## 🤖 Tools

Small, opinionated conventions and servers I use every day with Claude Code, Codex and friends, plus a few libraries.

| | |
|---|---|
| [**agent-plans**](https://github.com/alvaro-francisco-gil/agent-plans) | A lifecycle convention for plan documents (ideas → ready → ongoing), shipped as a plugin for Claude Code, Codex, Cursor and Gemini. |
| [**agent-record**](https://github.com/alvaro-francisco-gil/agent-record) | Conventions for a repo that holds an authoritative record agents can work from. |
| [**agent-skills**](https://github.com/alvaro-francisco-gil/agent-skills) | An autonomous delivery contract (`ship-a-feature`) and the state machine that lands its PRs. |
| [**agent-mail**](https://github.com/alvaro-francisco-gil/agent-mail) | Read-only mailbox access over MCP. Nothing in it can send, delete or modify mail, and tests enforce that. |
| [**musrank**](https://github.com/ordago-app/musrank) | A skill-rating system built for *mus*: a faster, open-license alternative to TrueSkill, published on npm. Made for Órdago. |
| [**talk-studio**](https://github.com/alvaro-francisco-gil/subtitler) | Agents propose edits to a recorded talk (audio clean-up, mastering, grading); a human picks blind. |

## 🔬 Research

Eight papers across astrodynamics, bio-signals, primate behaviour and team dynamics. First author on three. The through-line is the method: learn a domain with real experts in it, then apply generative or analytical models to what they actually need.

- **Generation of Periodic Orbits in the Restricted Three-Body Problem with a VAE** · *Celest. Mech. Dyn. Astron.*, 2026 · [paper](https://link.springer.com/article/10.1007/s10569-026-10299-x) · [code](https://github.com/alvaro-francisco-gil/orbit-generation)

- **Generative Astrodynamics: Trajectory Analysis and Design in the R3BP** · *AAS/AIAA SFMC*, 2025 · [paper](https://pureportal.strath.ac.uk/en/publications/generative-astrodynamics-trajectory-analysis-and-design-in-the-re/)
